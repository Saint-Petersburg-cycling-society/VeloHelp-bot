# Безопасность / Security

## RU

Для уязвимостей используйте приватную форму [Report a vulnerability](https://github.com/Saint-Petersburg-cycling-society/VeloHelp-bot/security/advisories/new).
Не публикуйте рабочие токены, личные Telegram ID, адреса, координаты или выгрузки БД в Issues.
Опишите воспроизведение на тестовых данных, последствия и затронутый commit.
Проект находится в стадии пилота; исправления готовятся для текущей ветки `main`.
Подробности обработки данных: [docs/SECURITY_PRIVACY.md](docs/SECURITY_PRIVACY.md).

## EN

Use [Report a vulnerability](https://github.com/Saint-Petersburg-cycling-society/VeloHelp-bot/security/advisories/new) for private disclosure.
Do not post live tokens, personal Telegram IDs, addresses, coordinates or database exports in Issues.
Include reproduction steps using test data, impact and the affected commit.
This is a pilot; fixes target the current `main` branch.
See [docs/SECURITY_PRIVACY.md](docs/SECURITY_PRIVACY.md) for data handling details.
