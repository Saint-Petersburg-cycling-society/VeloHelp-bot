# Documentation policy / Политика документации

## RU

Документация — часть изменения, а не post-hoc комментарий.

MUST:
- RU + EN;
- обновляться в том же PR/коммите, что и поведение;
- содержать те же MUST/MUST NOT/invariants;
- менять schema/state-machine docs вместе с migration/code.

## EN

Documentation is part of the change, not post-hoc commentary.

It MUST remain bilingual, change atomically with behavior, preserve the same
normative invariants in both languages, and update schema/state-machine docs
together with migrations/code.
